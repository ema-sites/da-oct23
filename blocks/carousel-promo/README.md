# carousel-promo

Custom **carousel** block. Purpose: full-width rotating promo banners with prev/next arrows and dot pagination in a control bar below the slides; autoplays (pauses on hover/focus, off with reduced motion).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = slide image (link the image for banner-only slides); cell 2 (optional) = logo image, heading/paragraphs (draw date, jackpot lines) and a CTA link. Leave cell 2 empty for image-only banner slides.

## Supported variations

No variations.
