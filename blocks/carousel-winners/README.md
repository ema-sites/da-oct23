# carousel-winners

Custom **carousel** block. Purpose: winner spotlight slider (portrait, name, location, CTA, game logo, ribbon label and boxed prize amount) over an illustrated background, with side arrows and dots.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per slide; cell 1 = background illustration image; cell 2 = portrait image, heading (winner name), location paragraph, CTA link, then game logo image, ribbon label paragraph (e.g. Winner) and prize amount paragraph (e.g. $500 000). The second image in cell 2 starts the prize group; digit groups of the amount are boxed automatically.

No variations.
