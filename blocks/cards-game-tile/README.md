# cards-game-tile

Custom **cards** block. Purpose: shadowed game/promo tiles in a 2-column grid with optional corner flag, draw info and a full-width CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per tile; cell 1 = tile image (optionally linked); cell 2 = optional short flag paragraph before the heading (e.g. NEW, shown as an image corner flag), heading (title), description paragraph, optional next-draw/jackpot paragraphs, and a CTA link as the last paragraph.

## Supported variations

No variations.
